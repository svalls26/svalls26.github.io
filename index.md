  <h1 class="bio__eyebrow">About me</h1>
  <p><strong>I am currently looking for PhD opportunities to continue my academic journey. If you liked my profile and have an interesting opportunity, let’s talk!</strong> I recently completed the MPhil in Machine Learning and Machine Intelligence at the University of Cambridge.</p>
  <p>For my dissertation, I created a human–AI collaboration system to help reconstruct manuscripts from the <a href="https://www.cam.ac.uk/stories/discarded-history-treasures-of-the-cairo-genizah">Cairo Genizah</a>. Developed through a participatory design approach with scholars, the system uses a computer vision pipeline to retrieve potential joins based on visual similarity. The project was selected for the <a href="https://www.ai.cam.ac.uk/news/from-safer-workplaces-to-medieval-manuscripts-five-new-ai-deas-projects-put-ai-to-work-on-real-world-problems/">ai@cam AI-deas Sprint</a> to develop it into a production-ready system for practical use.</p>
